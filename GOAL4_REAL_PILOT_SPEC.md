# Goal4 Real BioLab Pilot

默认 Work：Dataset→Reviewed Scientific Claim。

真实数据优先：用户提供→仓库已有来源/许可证清晰→环境允许下载的公开数据。否则只做 adapter/contract，不伪造 real pilot。

PilotManifest：source、license、dataset id/version、checksum、acquisition date、subset rule、preprocessing、schema、reference evidence。

Run：Real Dataset→immutable snapshot→pre-run predictions→Managed Work→QC→Analysis→Review→Claim→independent acceptance→actual metrics→prediction error→calibration。

Goal4 只证明工作系统与预测闭环，不把单个公开数据集包装成新的生物医学结论。
